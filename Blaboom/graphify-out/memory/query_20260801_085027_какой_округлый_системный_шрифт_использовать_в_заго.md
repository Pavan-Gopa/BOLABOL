# Q: Какой округлый системный шрифт использовать в заголовке Blaboom без контейнера, вложения файла и установки пользователем?

## Answer

Expanded from original query via graph vocab: [comic, font, system, title, wordmark, package]. Для macOS следует использовать системный SF Pro Rounded через SwiftUI Font.system(size:weight:design: .rounded), а не обращаться к файлу или PostScript-имени. Это убирает зависимость от установленного Comic Sans и не требует упаковки шрифта.
