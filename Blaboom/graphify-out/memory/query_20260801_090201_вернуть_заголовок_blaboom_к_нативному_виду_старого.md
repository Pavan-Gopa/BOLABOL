# Q: Вернуть заголовок Blaboom к нативному виду старого SmartScribe, изменив только имя и округлый шрифт

## Answer

Expanded from graph vocab: [title, system, window, wordmark]. Historical SmartScribe source confirmed it used Window("SmartScribe") with the native visible title and no ToolbarItem. Blaboom now uses Window("BLABOOM!"), titleVisibility visible, no navigation ToolbarItem, and applies the rounded system design to the existing native title text field while preserving its original point size and layout. Tests passed; fresh signed app launched and visually verified.
