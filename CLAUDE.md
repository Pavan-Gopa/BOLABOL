# CLAUDE.md

This is the `AI Projects` workspace root, not an application checkout.

Before changing code, move into the owning project directory. For example:

```bash
cd SmartScribe/Electron
cd VaniScript/Electron
cd VaniScript/AppleSilicon
```

Do not create app source files, build outputs, package manifests, or runtime assets in this root folder. Use `scripts/check-workspace-root-clean.sh` to verify the root stays clean.
