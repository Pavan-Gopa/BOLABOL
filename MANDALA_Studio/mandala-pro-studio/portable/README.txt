  MANDALA STUDIO — Portable
════════════════════════════════════════════════════════

FOR WINDOWS (most common)
-------------------------
1. Unzip this folder anywhere (Desktop is fine).
2. Double-click:   Start-Mandala.bat
3. Browser opens automatically.
4. Keep the black window open while using the app.
5. Close that window when you are done.

If Windows blocks the script:
  • Right-click Start-Mandala.ps1 → "Run with PowerShell"
  • Or: Properties → Unblock → OK, then run the .bat again.


FOR MAC
-------
1. Unzip the folder.
2. Double-click:   Start-Mandala.command
   (If macOS says it cannot open: right-click → Open → Open)
3. Browser opens at http://127.0.0.1:3847/


WHAT YOU NEED
-------------
• Windows 10/11 with PowerShell (built-in) — no install
• Or Mac with Python 3 (usually built-in)
• A modern browser (Chrome, Edge, Safari, Firefox)


YOUR DRAWINGS
-------------
Projects are saved in the browser (local storage).
They stay on this computer / this browser profile.
To share a mandala: use Export (PNG) or Share code inside the app.


TROUBLESHOOTING
---------------
• Port busy → the script tries another port; check the black window for the URL.
• Blank page → make sure you started via the .bat / .command, not by opening index.html alone.
• Antivirus → allow local server on 127.0.0.1 (only your PC).


Enjoy painting ✨
