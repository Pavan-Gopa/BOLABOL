# 00. Обзор приложения

## Сюжет для видео

SmartScribe Native - это macOS-приложение для локальной диктовки, транскрибации, улучшения текста, перевода и вставки результата в активное приложение. Важная идея: транскрибация может работать локально через WhisperKit/Core ML, polishing может работать локально через MLX-модели или через API-провайдеры.

В начале tutorial стоит объяснить архитектуру простыми словами:

- Слева находится история заметок.
- Справа находится рабочая область текущей записи.
- Внизу расположены действия: запись, импорт аудио, перевод, polishing, настройки.
- В Settings настраиваются модели, API, hotkeys, HUD, prompts, glossary, статистика и справка.

## Что важно подчеркнуть

- Native версия не является Electron-приложением; это Swift/SwiftUI app для macOS.
- Приложение ориентировано на Apple Silicon и локальные модели.
- Главный рабочий цикл: выбрать локальную модель транскрибации, выбрать polishing engine, записать или импортировать аудио, получить Raw text, затем Variant 1 / Variant 2 / Markdown.
