# 06. General Settings

## `07_general_settings.png`

General contains appearance, UI scale, interface language, HUD, logging, and troubleshooting settings.

## Screenshot Explanation

- Theme: Dark, Light, System.
- UI Font Size: global UI scale.
- Interface Language: app language.
- Overlay HUD: size, transparency, start/finish sound, and volume.
- Log Level: app logging verbosity.
- Troubleshooting: export system logs and reset general settings.

## Narration Points

HUD settings do not control the main window. They control the floating overlay shown during hotkey recording. If the user does not use hotkeys, the HUD is rarely visible.

Export System Logs writes diagnostics under `~/Library/Application Support/NativeSmartScribe/Logs/`. It helps debug recording, model, and permission issues.
