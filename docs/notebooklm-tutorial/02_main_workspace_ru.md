# 01. Главное рабочее окно

## `02_main_01_window_initial.png`

Показывает основное окно SmartScribe. Слева - список записей/заметок с датой и preview-текстом. Справа - выбранная заметка: сверху метаданные аудио, затем выбор transcription model и polishing model, ниже переключатель Raw / Variant 1 / Variant 2, основное текстовое поле и нижняя панель действий.

Для видео: объяснить, что SmartScribe работает как dictation notebook. Каждая запись сохраняется как отдельная note, а пользователь может копировать отдельную заметку или все заметки из sidebar.

## `02_main_02_raw_tab.png`

Raw - это исходный результат транскрибации. Это максимально близкий к аудио текст до творческого polishing. Raw полезен для проверки точности распознавания и как основа для дальнейших вариантов.

## `02_main_03_variant_1_tab.png`

Variant 1 - лёгкая чистка диктовки. Обычно она убирает повторы, filler words, self-corrections, но сохраняет язык, смысл и общий уровень детализации. В правом верхнем углу видны prompt slots: `D`, `1`, `2`, `3`, `4`, а также кнопка `M` для Markdown.

## `02_main_04_variant_2_tab.png`

Variant 2 - более сильное переписывание. Его задача - сделать текст яснее, структурнее и точнее. Это не перевод и не добавление новых фактов; это более активная редактура того же смысла.

## `02_main_05_transcription_model_menu.png`

Меню выбора локальной модели транскрибации в рабочем окне. В нём отображаются только уже доступные/активные модели. Для установки новых моделей пользователь идёт в Settings -> Local Models.

## `02_main_06_polishing_model_menu.png`

Меню выбора polishing engine. Здесь могут быть:

- `Polishing Disabled`
- локальные MLX-модели, например Qwen
- API provider, например Google Gemini, если ключ настроен

Для видео: подчеркнуть, что transcription model и polishing model - это разные вещи. Первая распознаёт аудио, вторая редактирует текст.
