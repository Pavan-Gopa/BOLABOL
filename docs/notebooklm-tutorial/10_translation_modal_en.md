# 09. Translation Modal

## `10_translation_modal.png`

The Translation modal opens from the main window bottom bar. It translates selected text or clipboard text. The screenshot shows provider, target language, original panel, translated panel, record button, refresh, and translate button.

## Narration Points

- The provider can be a local MLX model or an API provider.
- Target Language can be selected or typed manually.
- Original text is editable.
- Translated text shows the result and can be copied.
- The record button inside the modal lets the user dictate text specifically for translation.
- Glossary can be applied to the translated result by target language.

## Difference from Variant 1 / Variant 2

Variant 1 and Variant 2 edit text in the same language. The Translation modal changes the output language. It is a separate workflow.
