# 10. Statistics and Help

## `11_statistics_settings.png`

Statistics shows token usage:

- last transaction: prompt tokens, completion tokens, total tokens;
- total usage for the selected model/provider;
- reset stats for the selected model.

This is useful for API providers and MLX workflows where prompt size matters.

## `11_help_settings.png`

Help is the built-in guide. It covers:

- quick start;
- recording and HUD;
- offline transcription;
- polishing providers;
- import and translation;
- permissions;
- privacy.

For a tutorial video, this screen works as a closing overview: it confirms that the tutorial covered the same blocks the app itself treats as core.
