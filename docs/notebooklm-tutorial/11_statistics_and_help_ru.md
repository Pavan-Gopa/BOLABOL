# 10. Statistics и Help

## `11_statistics_settings.png`

Statistics показывает usage по токенам:

- last transaction: prompt tokens, completion tokens, total tokens;
- total usage по выбранной модели/provider;
- reset stats для выбранной модели.

Это полезно для API-провайдеров и MLX workflow, где важно понимать объём запросов.

## `11_help_settings.png`

Help - встроенная справка. Она покрывает:

- quick start;
- recording and HUD;
- offline transcription;
- polishing providers;
- import and translation;
- permissions;
- privacy.

Для видео этот экран можно использовать как финальный overview: он подтверждает, что весь tutorial прошёл по тем же блокам, которые само приложение считает ключевыми.
