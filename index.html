Welcome to SmartScribe

Effortless dictation and note polishing. Record, transcribe locally with Whisper, the state of the art models for speech recognition by OpenAI, and polish with cloud or local LLMs.

Quick Start

  • Click Record to capture audio. Click again to stop.
  • Use Raw, Variant 1, Variant 2 tabs to view outputs.
  • Use Copy to copy the current tab’s text.

Offline Transcription

  • Open Settings → Local Models and install a Whisper model.
  • Click the installed model to activate it.
  • In the header, choose Local as the Transcription Provider.

Polishing Providers

  • Configure Google, OpenAI, Anthropic, or Custom in Settings → API Providers.
  • Or connect to a local Ollama server in Settings → Local LLM.
  • Variant prompts are in Settings → Custom Prompt.

How Local Whisper Works

  • Models: Small/Medium English-only are available in Settings → Local Models.
  • Backends: CPU, or GPU via Vulkan (Windows/Linux) and Metal (macOS).
  • GPU Badge: After your first local transcription, the app shows CPU or GPU, indicating Vulkan/Metal acceleration is engaged.
  • If GPU fails, it falls back to CPU and shows a failure tooltip with the reason.
  • For bigger Whisper models you need a larger GPU VRAM for comfortable use in GPU acceleration mode.

How Local LLM (Ollama) Polishing Works

  • Connect an Ollama server in Settings → Local LLM (local or remote).
  • We send strict instructions and use JSON-style parsing to avoid extra chatter and keep the original language.
  • Choose your model in the header dropdown for Variant 1/2 polishing.
  • For Local LLM models you need at least 8GB of GPU VRAM for comfortable use in GPU acceleration mode.

Translation

  • Select text and click Translate to open the translation modal.
  • Pick a target language or add more from Custom Language.
  • Hint: Local Whisper can directly translate speech to English when you press Record in the translation modal.

Hotkey

  • Enable the Global Hotkey in Settings → Hotkey.
  • Choose target (Raw/V1/V2) and action (Clipboard/Typing).

Privacy & Troubleshooting

  • Local transcription runs on-device; no audio leaves your machine.
  • Use Settings → General → Log Level and Open Log File for diagnostics.
  • GPU badges appear after first local transcription.
